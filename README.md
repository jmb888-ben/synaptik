# Jim Ben Soussan — Artbook numérique
Ouvrir index.html après extraction. Le site est statique, sans dépendance de build. Les 16 films sont répartis en quatre chapitres, avec fiches individuelles, carnets de photogrammes, biographie et contact.

## Avant publication
Importer uniquement cette archive dans un nouveau dépôt et configurer un domaine personnel. Vérifier les droits de diffusion, les logos présents dans les vidéos et les métadonnées du lecteur Vimeo. L'ancien showreel n'est pas inclus. Quinze vignettes sont locales ; la vignette de Saturnin est distante, avec repli typographique. Le lien de contact est le LinkedIn public ; ajouter une adresse personnelle autorisée si souhaité. Compléter les crédits et dates vérifiés, les métadonnées vidéo, les URL canoniques et le sitemap lorsque le domaine est défini. Tester la lecture en ligne et les appareils réels avant publication.

## Direction artistique
Éditorial cinéma : noir, ivoire, sérif, grands photogrammes intacts, chapitres et légendes. Carnets : analyses d'images existantes, pas de storyboards inventés. Motion d'après les principes d'Emil Kowalski : CSS léger, transform/opacity, interactions brèves, survol réservé au pointeur fin et préférence de mouvement réduit respectée.
